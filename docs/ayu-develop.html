Design decisions

Decision Rationale Tradeoff Evidence
Store evaluation before notifying consumers. Subscribers can query consistent typed/time-scoped matrix values when they wake. Consumers must respect freshness and full-cycle validity checks. MatrixChannelProducer.send_eval_note (L80) / StrategyEvaluator.start (L58)

Workflow

Host candle evaluation

Concrete indicator and aggregation formula implementations are supplied by Tentacles; no order execution engine is declared here.

  W1["Price-ready callback executes concrete evaluator, then evaluation_completed."]
  W0 --> W1
  W2["Write evaluation and enqueue filtered notifications."]
  W1 --> W2
  W3["Host-created StrategyEvaluator consumes matrix update and emits result."]
  W2 --> W3
  1. Host OctoBot-Trading channel delivers OHLCV event.. TAEvaluator.start (L40)

  3. Write evaluation and enqueue filtered notifications.. MatrixChannelProducer.send_eval_note (L80) / MatrixChannelProducer.send (L45)
  4. Host-created StrategyEvaluator consumes matrix update and emits result.. StrategyEvaluator.start (L58) / StrategyEvaluator.strategy_completed (L73)

Sequence

Store before notify

Queue delivery is asynchronous, not a direct call from producer to StrategyEvaluator.

Diagram source

  participant N0 as AbstractEvaluator
  participant N1 as MatrixChannelProducer
  participant N2 as StrategyEvaluator
  N0->>N1: send_eval_note after cache/expiry checks
  N1->>N1: set_tentacle_value then send to filtered queues
  N1->>N2: Deliver matrix update through subscribed consumer
  • send_eval_note after cache/expiry checks: AbstractEvaluator.evaluation_completed (L273)
  • set_tentacle_value then send to filtered queues: MatrixChannelProducer.send_eval_note (L80) / MatrixChannelProducer.send (L45)
  • Deliver matrix update through subscribed consumer: MatrixChannelProducer.send (L45) / StrategyEvaluator.start (L58)

Strengths and limits

Strengths

  • Matrix paths and filtered queues retain evaluator/exchange/symbol/timeframe identity. MatrixChannelProducer.send_eval_note (L80) / MatrixChannelProducer.send (L45)

Limitations

  • Base OHLCV callback is a hook; concrete formulas are supplied by installed tentacles. TAEvaluator.evaluator_ohlcv_callback (L85) / TAEvaluator.start (L40)
